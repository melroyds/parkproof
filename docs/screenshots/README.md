## Tips for nicer screenshots

- Use Chrome's **device mode** (`F12` → toggle device toolbar → iPhone 14 Pro at 100%) so the screenshots are mobile-shaped — the app is designed mobile-first and looks awkward at desktop width.
- For the result screen, scan a real Melbourne sign at lunchtime so `Until 2:00 pm (1h 23m)` feels concrete rather than synthetic.
- A 5–10s screen recording of the full flow makes a great portfolio asset too — record once, embed at the top of the README as a `.gif` or unlisted YouTube.

The current README references each file by name; if you skip one, just remove the corresponding `<img>` line from the demo grid.
